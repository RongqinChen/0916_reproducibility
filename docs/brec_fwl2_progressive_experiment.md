# BREC 逐层 2-FWL Pair Encoding 实验记录

本次实验在 BREC 中标准 2-FWL 可区分的 270 个非同构图对上评估逐层数值编码，并检查 BREC 自带的 8,640 个同构对照。第 0 层沿用原编码，区分 230 对。新增的联合收缩层区分了剩余 40 个 CFI 图对，最终覆盖 **270/270**，官方同构对照 **8,640/8,640 全部通过**。

## 编码定义和停止规则

### 第 0 层沿用原编码

设 $A$ 为邻接矩阵，$D$ 的对角元为 $d_v=\max(1,\deg v)$，并令 $S=D^{-1/2}AD^{-1/2}$。本次单项式基使用 $B_a=S^a$，其中 $B_0=I$。定义端点特征 $h_a(u)=\sum_w B_a(u,w)$。每个有序节点对 $(u,v)$ 的基线 $\Phi_{Q,0}(u,v)$ 包含以下特征。

- 常数 $1$、$I_{uv}$、$A_{uv}$，以及从 $B_1(u,v)$ 到 $B_Q(u,v)$ 的多项式特征。
- 所有满足 $a,b\geq 0$、$0<a+b<Q$ 的端点乘积 $h_a(u)h_b(v)$。

当 $Q=16$ 时，完整定义有 154 个通道。实现比较时保留 49 个通道。由于 $h_0=1$，原编码已经包含 $h_a(u)$ 和 $h_b(v)$ 两个因子，混合端点乘积可以从保留通道逐行重建。这保留了完整编码行的多重集判定。

基线从整数形式的多项式矩阵恢复精确值。令 $R=D^{-1}A$ 且 $L=\operatorname{lcm}(d_1,\ldots,d_n)$，则 $L^aR^a$ 的元素为整数。通过 $S^a=D^{1/2}R^aD^{-1/2}$ 恢复归一化特征。实现使用 Python 整数、`Fraction` 和规范化的根式表示完成精确比较，适用于非正则图。[基线实现](../rebuttal_experiments/triple_exact.py) · [整数多项式矩阵](../rebuttal_experiments/polynomial_banks.py)

### 每轮追加两个数值通道

令通道索引 $j\in\{0,1\}$，模数 $(m_0,m_1)=(16777213,16777199)$。两个通道的初始状态均为 $Z_{0,j}=2I+A$，由第 0 层的节点对类型确定。第 $t$ 轮使用上一轮对应通道的状态，令

$$
\begin{aligned}
\alpha_{t,j} &= (7853+104729t+7919j)\bmod m_j,\\
\beta_{t,j} &= (65537+130363t+6511j)\bmod m_j.
\end{aligned}
$$

$$
Z_{t,j}(u,v)=
\left[
Z_{t-1,j}(u,v)
+\sum_w
\bigl(Z_{t-1,j}(u,w)+\alpha_{t,j}\bigr)^5
\bigl(Z_{t-1,j}(w,v)+\beta_{t,j}\bigr)^7
\right]\bmod m_j.
$$

同一个中间顶点 $w$ 把 $(u,w)$ 和 $(w,v)$ 两项耦合起来。实现采用 NumPy `uint64` 做整数矩阵乘法和取模，乘积累加超过安全上界时分块取模。每张图可以用同一组固定常数独立计算，无需图批次级颜色字典、拟合参数或随机采样。[联合收缩实现](../brec/fwl2_numeric.py)

第 $t$ 层编码定义为 $\Phi_{Q,t}=(\Phi_{Q,t-1}, Z_{t,0}, Z_{t,1})$。读出比较整行的联合多重集。实现按有序节点对的自同构轨道取代表元，使用轨道大小作为整数权重，精确计入全部 $n^2$ 行。轨道编号不进入数值特征。[逐层比较实现](../brec/fwl2_progressive.py)

### 复用状态和提前停止

程序先构造一次第 0 层，比较两侧的精确多重集。若相同，只从已有状态计算下一轮的两个通道，再将它们追加到上一层的行。若不同，记录首个区分层、一个不同的特征行及其在两图中的次数，并立即结束主图对的计算。

第 $t$ 层的完整行多重集投影到旧通道后，会恢复第 $t-1$ 层的多重集。因此，只要较低层已经区分，高层保留这些通道时就必然继续区分。这个性质允许跳过对应图对在后续层的计算和比较。有限模数允许状态合并，因此本次结果给出这一设置在所测 270 对上的覆盖率。

## BREC 官方同构对照

可靠性检查只使用 BREC 自带的同构图对。对每个主图对 ID $p$，读取官方可靠性区块中的 64 条记录，从索引 $64(p+400)$ 开始，两两相邻组成 32 组。每组的两个图独立计算同一编码前缀，检查深度与对应主图对的实际停止层一致。

程序用 nauty 的规范顶点排序求出对照图之间的顶点映射，并验证映射后的邻接矩阵逐项相等。第 0 层对齐并检查用于重建归一化多项式特征和全部端点乘积的精确整数矩阵。若需要数值扩展，则继续验证该深度以内的全部模整数通道逐项相等。这些检查覆盖完整前缀及其多重集。[官方数据和顶点映射实现](../rebuttal_experiments/brec_data.py) · [编码前缀对照实现](../brec/fwl2_progressive.py)

## 调度和耗时

所有工作都在 CPU 上执行，包括精确基线、NumPy 整数收缩和 BREC 官方对照。实验按主图的 graph6 记录长度从大到小提交任务，以优先处理预计工作量较大的对照区块。每个 worker 完成主图对和对应的 32 个官方对照后，进度条增加一对。最终进度为 `2-FWL encoding [====================] 270/270`。

主图对总共执行 $34\times4+6\times5=166$ 个图对轮次。若 270 对都固定运行 5 轮，则需要 1,350 个图对轮次。逐层提前停止省去 1,184 个图对轮次，减少 **87.7%**。一个图对轮次包括两侧图的数值更新。这个比例以收缩轮数为单位。

2026 年 11 月 19 日北京时间，输出目录中的运行锁创建于 **14:13:44.298**，完成清单写于 **14:13:53.170**。两者相差约 **8.9 秒**，这是按文件时间戳估算的运行目录内耗时。启动环境和进入运行目录前的数据及源码校验不在这一时间区间内。

```bash
  --base-q 16 --basis monomial --variant endpoint --numerical-rounds 5
```

只复查指定图对时，把 `--full` 改为 `--progressive --pair-ids`，随后给出 ID。实验清单记录输入哈希、实际参数、软件包版本和完成状态。原运行状态为 `execution_finished`，生成了 **270 条逐对 JSON 记录和 270 个 NPZ**。[实验入口](../brec/fwl2_encoding.py) · [运行清单](../outputs/brec_fwl2_progressive_270/fwl2_encoding/manifest.json) · [结果汇总](../outputs/brec_fwl2_progressive_270/fwl2_encoding/summary.json)

逐对记录包含首个区分层、实际计算轮数、区分证据和通过的官方对照记录编号。NPZ 保存左右邻接矩阵，并在第 0 层以外保存实际计算到的数值前缀。前缀包含一个初始类型通道和每轮两个模整数通道。第 0 层的精确特征可从邻接矩阵和清单中的基线设置重建。

复核覆盖了 270 个主图对的产物和 8,640 个官方对照编号。对进入数值扩展的 40 个图对，左右两侧保存的数值前缀都与逐图一次性计算 5 轮后截取的前缀逐项一致。原运行后的 BREC 测试共执行 56 项，其中 55 项通过、1 项跳过。[逐层早停和对照测试](../tests/test_brec_fwl2_encoding.py)
